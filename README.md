# ThyGap

**Know thy math.** An AI tutor that reasons its way to the one concept a student is really missing, so they can finally understand the problem they were stuck on.

Made for the Meta Global AI Developer Hackathon 2026, Indie track; the app is built during the event.

## What is here

- `plan/`: the planning document (chapters 1–19 and an appendix on how the app is built), prepared before the event (see `PRE-EXISTING.md`).
- The build script that sends the work cards to the Meta model and runs the checks and tests was also prepared before the event; it is kept outside this repository.
- Everything else in this repository will be made during the hackathon building period by a Meta model, from the plan.
- `build-log/` (will be written during the event): the build log, one file per work card, with the Meta model and the time.
